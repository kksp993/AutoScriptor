## 快速上手

假设你玩的是"琉离"职业，想改一下战斗配招。

1. 用记事本打开 `profiles/琉离/技能/战斗.yaml`
2. 修改技能顺序、等待时间等
3. 保存，重新登录角色即可生效

就这么简单。下面详细解释每个部分怎么写。

---

## 核心概念

配招系统分成两种文件：

| 文件类型 | 放在哪个文件夹 | 干什么 |
|---------|-------------|--------|
| **技能文件** | `技能/` 文件夹下 | 定义"按什么顺序出招" |
| **流程文件** | `流程/` 文件夹下 | 定义"怎么循环使用技能" |

**技能文件**就是一张出招表，告诉脚本按什么顺序按哪些键。
**流程文件**就是一个战斗计划，告诉脚本什么时候打、什么时候赶路、什么时候放化身。

## 第一部分：指令手册

以下是你在技能文件中可以使用的所有指令。

### 技能键

点按技能栏对应的技能按钮。

| 写法 | 效果 |
|------|------|
| `技能1` | 点按技能1 |
| `技能2` | 点按技能2 |
| `技能3` | 点按技能3 |
| `技能4` | 点按技能4 |
| `技能5` | 点按技能5 |
| `技能6` | 点按技能6 |
| `技能4:1.5` | **长按**技能4，持续 1.5 秒 |
| `技能1:3` | **长按**技能1，持续 3 秒 |

> 规则：`技能N` 点按，`技能N:秒数` 长按。N 为 1~6。

### 移动

| 写法 | 效果 |
|------|------|
| `左移` | 点按一次左移（轻移） |
| `右移` | 点按一次右移（轻移） |
| `左移:125` | 向左滑步，距离 125 |
| `右移:200` | 向右滑步，距离 200 |

> 规则：不带数字是轻点一下，带数字是滑步移动（数字越大走越远）。

### 跳跃

| 写法 | 效果 |
|------|------|
| `跳跃` | 跳一次 |
| `跳跃:2` | 连跳 2 次 |
| `跳跃:3` | 连跳 3 次 |

> 规则：不带数字跳 1 次，带数字跳 N 次。

### 等待

| 写法 | 效果 |
|------|------|
| `等待:0.5` | 等待 0.5 秒 |
| `等待:2` | 等待 2 秒 |

> 等待是必须带数字的，表示暂停几秒。用于技能之间需要间隔时。

### 道具

| 写法 | 效果 |
|------|------|
| `法宝1` | 点击法宝 |
| `法宝2` | 点击仙宝 |
| `无双` | 点击无双 |

> 这三个也支持长按，写法同上：`无双:2` 表示长按无双 2 秒。

### 特殊技能

| 写法 | 效果 |
|------|------|
| `化身` | 点击化身 1 次 |
| `化身:3` | 点击化身 3 次 |
| `真武` | 点击真武（本命神） |
| `本命神` | 同上，和"真武"等价 |
| `合体` | 点击合体 |
| `攻击` | 点击攻击键 |
| `攻击:2` | 长按攻击键 2 秒 |

> `化身` 的数字表示**点击次数**（不是长按）。其他都是长按秒数。

## 第二部分：编写技能配招

### 基本格式

一个技能文件的写法：

```
配招名称:
  - 指令1
  - 指令2
  - 指令3
```

**格式要求**（严格遵守）：
- 配招名称后面必须有英文冒号 `:`
- 每条指令前面是 **2个空格 + 短横线 + 1个空格**，即 `  - `
- 指令中的冒号 `:` 和数字之间**不要加空格**（写 `技能4:1.5`，不要写 `技能4: 1.5`）

### 示例：定义一套战斗配招

```
我的战斗招:
  - 法宝1
  - 法宝2
  - 无双
  - 右移
  - 技能1
  - 等待:0.5
  - 左移
  - 技能4
  - 跳跃
  - 技能6
```

意思是：先开三个道具 → 右移 → 放技能1 → 等 0.5 秒 → 左移 → 放技能4 → 跳 → 放技能6。

### 一个文件可以定义多套配招

只需要空一行隔开：

```
战斗_有cd_1x:
  - 右移
  - 技能1
  - 等待:0.5
  - 技能4

战斗_有cd_3x:
  - 右移
  - 技能1
  - 等待:0.2
  - 技能4
```

### 引用其他配招

你可以在配招中引用已经定义好的配招名称，让它自动展开。

比如 `default/技能/` 下已经定义了 `道具全开`：

```
道具全开:
  - 法宝1
  - 法宝2
  - 无双
```

那你在自己的配招里可以直接写：

```
我的赶路:
  - 道具全开
  - 跳跃:2
  - 右移:125
  - 技能1
  - 技能4:1
```

`道具全开` 会自动展开为"法宝1 → 法宝2 → 无双"三步。

**你自己定义的配招也可以被别的配招引用**，只要名字对得上就行。

## 第三部分：编写战斗流程

流程文件比技能文件复杂一些，但结构是固定的。

### 完整流程模板

```
流程名称:
  策略:
    战斗:
      有cd:
        1倍速: 对应战斗配招名
        3倍速: 对应战斗配招名
      无cd: 对应战斗配招名
    赶路:
      有cd: 对应赶路配招名
      无cd: 对应赶路配招名

  初始:
    - 化身

  轮替:
    - 战斗:1
    - 赶路:1

  触发器:
    - 每: 60
      执行: 化身

  超时: 300
```

下面逐项解释。

### 策略

策略告诉脚本：**在不同情况下用哪套配招**。

```
  策略:
    战斗:
      有cd:
        1倍速: 战斗_有cd_1x
        3倍速: 战斗_有cd_3x
      无cd: 战斗_无cd
```

意思是：
- 有 CD 且 1 倍速时 → 用"战斗_有cd_1x"这套配招
- 有 CD 且 3 倍速时 → 用"战斗_有cd_3x"这套配招
- 无 CD 时（任意倍速） → 用"战斗_无cd"这套配招

倍速可以写 `1倍速`、`2倍速`、`3倍速`、`4倍速`，按需配置。如果当前倍速没有精确匹配，会自动使用最接近的那套。

你可以定义多个策略（比如"战斗"和"赶路"是两个策略），名字随便取。

### 初始

战斗开始前执行一次的动作。

```
  初始:
    - 化身
```

可以写多个：

```
  初始:
    - 等待:4.3
    - 化身
    - 真武
```

### 轮替

战斗循环中，**按什么顺序、什么比例**执行各个策略。

```
  轮替:
    - 战斗:1
    - 赶路:1
```

意思是：打 1 轮战斗，然后赶 1 轮路，循环往复。

```
  轮替:
    - 战斗:3
    - 赶路:1
```

意思是：打 3 轮战斗，然后赶 1 轮路。

```
  轮替:
    - 战斗:99
```

意思是：一直打，不赶路（打 99 轮才赶 1 轮，基本不会赶路）。

> 冒号后面的数字是**权重**，表示连续执行几轮。

### 触发器

战斗过程中，**满足条件时自动执行的动作**。

**每隔 N 秒执行一次：**

```
  触发器:
    - 每: 60
      执行: 化身
```

> 注意：`每:` 后面的冒号和数字之间**要有空格**（写 `每: 60`），这是流程文件特有的格式要求。

**在第 N 秒时执行一次：**

```
  触发器:
    - 时刻: 120
      执行: 真武
```

可以同时设置多个触发器：

```
  触发器:
    - 每: 60
      执行: 化身
    - 时刻: 10
      执行: 真武
```

### 超时

战斗最长持续多少秒，超过自动结束。

```
  超时: 300
```

300 = 5 分钟。

## 文件放在哪里

```
profiles/
  default/            ← 所有职业共享的通用配招
    技能/
      道具.yaml       ← 道具全开等通用组件
      移动.yaml       ← 无双左移等通用移动
    流程/
      战斗循环.yaml   ← 默认战斗流程
      竞技场.yaml     ← 默认竞技场流程
  琉离/               ← 琉离职业专属配招
    技能/
      战斗.yaml       ← 琉离的战斗配招
      赶路.yaml       ← 琉离的赶路配招
    流程/
      战斗循环.yaml   ← 琉离的战斗流程
      竞技场.yaml     ← 琉离的竞技场流程
```

### 添加新职业

1. 在 `profiles/` 下新建一个文件夹，比如 `法师/`
2. 在里面创建 `技能/` 和 `流程/` 两个文件夹
3. 在 `技能/` 下写你的配招文件
4. 在 `流程/` 下写你的战斗流程文件
5. 你可以直接引用 `default/` 里定义的通用组件（如 `道具全开`）

### 覆盖规则

- 你的职业文件夹里定义的配招，**优先于** `default/` 里同名的配招
- 如果你的职业里没有定义某个配招，会自动从 `default/` 里找

## 常见错误与排查

### 1. 缩进错误

**错误写法**（用了 Tab 或缩进不一致）：

```
我的配招:
- 技能1        ← 缺少缩进
    - 技能2    ← 缩进太多
```

**正确写法**（统一 2 个空格 + 短横线）：

```
我的配招:
  - 技能1
  - 技能2
```

### 2. 冒号后多了空格

在技能文件的指令中，冒号后**不要加空格**：

```
  - 技能4:1.5    ← 正确
  - 技能4: 1.5   ← 错误！会被识别为其他格式
```

但在流程文件的触发器中，`每:` `时刻:` 后面**必须加空格**：

```
    - 每: 60      ← 正确
    - 每:60       ← 错误！
```

> **简单记忆：指令不加空格，触发器要加空格。**

### 3. 引用了不存在的配招名

如果你写了 `- 超级爆发` 但没有任何文件定义过"超级爆发"，启动时会报错并提示找不到。检查名字是否拼写一致。

### 4. 文件格式

- 文件必须以 `.yaml` 结尾
- 文件编码必须是 **UTF-8**（记事本另存为时选择 UTF-8 编码）
- 文件名随便取，里面可以定义多个配招

## 完整示例

以下是一个从零开始为"法师"职业配招的完整示例。

### 第 1 步：创建目录

```
profiles/
  法师/
    技能/
    流程/
```

### 第 2 步：写技能文件

创建 `profiles/法师/技能/战斗.yaml`：

```
战斗_有cd_1x:
  - 道具全开
  - 技能2:1.5
  - 等待:0.3
  - 技能5
  - 跳跃
  - 技能1
  - 左移
  - 技能6

战斗_有cd_3x:
  - 道具全开
  - 技能2:1
  - 技能5
  - 技能1
  - 技能6

战斗_无cd:
  - 道具全开
  - 技能2:2
  - 跳跃:2
  - 技能1
  - 技能3
```

创建 `profiles/法师/技能/赶路.yaml`：

```
赶路_有cd:
  - 道具全开
  - 跳跃:2
  - 右移:200
  - 技能1
  - 技能4:1.5

赶路_无cd:
  - 道具全开
  - 跳跃:3
  - 右移:200
  - 技能1
```

### 第 3 步：写流程文件

创建 `profiles/法师/流程/战斗循环.yaml`：

```
战斗循环:
  策略:
    战斗:
      有cd:
        1倍速: 战斗_有cd_1x
        3倍速: 战斗_有cd_3x
      无cd: 战斗_无cd
    赶路:
      有cd: 赶路_有cd
      无cd: 赶路_无cd

  初始:
    - 化身

  轮替:
    - 战斗:2
    - 赶路:1

  触发器:
    - 每: 60
      执行: 化身

  超时: 300
```

完成！登录法师角色后脚本就会自动使用这套配招。
