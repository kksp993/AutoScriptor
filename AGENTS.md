# Agent Rules

This project uses shared agent rules in [docs/agents/project-rules.md](docs/agents/project-rules.md).

Codex must read and follow that file before project repair, feature work, task authoring, WebUI/backend changes, config/status work, deployment/update work, or live emulator testing.
