# 安全执行规则

执行游戏任务时，生成可以大胆，执行必须保守。

- 不要在低置信度时猜测点击。
- 不要点击无法解释用途的按钮。
- 对不可逆、消耗资源、购买、删除、确认交易等动作，必须先识别明确文案。
- 每次点击后都要重新截图或等待可观察状态变化。
- 如果页面与预期不符，先关闭普通弹窗或返回已知页面；仍不明确时停止并报告。
- 兑换码、账号状态、活动入口可能变化，不能把一次坐标当成永久规则。
- 失败归因要区分：导航失败、目标未找到、OCR/视觉误识别、输入失败、服务端返回兑换失败、账号条件不足。
- 隐私默认保护：不要把用户现场的真实内网地址、端口、模型部署名、账号、密码、token、角色列表、兑换码或截图文字写入脚本、文档、测试或 skill。
- 需要展示配置时统一使用 `YOUR_*`、`example.invalid`、`<placeholder>` 这类占位符。
- 用户提供的 endpoint/model 只用于当前调试连接，不固化到仓库产物。
