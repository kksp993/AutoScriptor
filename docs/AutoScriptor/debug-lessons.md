# 失败排查速查

上限 1000 字；只留可复用结论，满了先合并同类项。写现状，不写历史。

## 根因优先级

1. **固定 sleep 等界面**：合成/动画时长不定，到点界面可能还在变。
   一律 `ui_T` 等出现 → `click(..., until=ui_F(...))` 等消失。
2. **遮罩吞点击**：弹窗遮罩压暗页面并吃掉点击，且不会自己消失；
   此时点关闭按钮无效，后面全超时。判据：目标区近白像素归零、亮度减半。
3. **裸 Box 当识别目标**：`Box` 是 namedtuple，被当多目标元组解析 →
   `Unsupported target type: <class 'int'>`。用 `B(...)` 包一层。
4. **日志会漏读**：`_log_action` 对同类动作按 1 秒合并，合并了多少条写在下一行，
   「日志没这一行」不等于没执行。判断某步点没点，看归档的 `action_history`。

## 手法

- 日志 `模块:行号` 直接映射源码，别猜。
- 遮罩/状态用像素统计（亮度、近白像素）定量判，不靠肉眼。
- 读数存疑就离线 OCR 复现，只读归档 PNG，不碰设备。
- 同代码路径取成功/失败各一次对照，比单看失败快。
- 只在真运行暴露的（如服务起来才 500 的接口）用真起服务的冒烟测试兜。
- 归档里已有什么、按什么顺序看，见 `operations/log-archiver.md`。
