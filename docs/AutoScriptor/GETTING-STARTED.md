# 从零开始

照着做一遍就能用上。每一步都写了「成功是什么样」和「不对时怎么办」。

安装与更新的完整参数见 [INSTALL.md](INSTALL.md)；本文只讲怎么走完全程。

---

## 0. 你需要准备什么

| | 说明 |
|---|---|
| Windows 10 / 11（64 位） | 目前只支持这个 |
| 模拟器 | MuMu 模拟器（建议 12）。装在哪个盘、哪个目录都行，后面会自动找 |
| 游戏账号 | 《造梦西游 OL》的账号密码。会加密后存在你自己电脑上 |
| 网络 | 第一次要下载依赖（Python 依赖约几百 MB，OCR 模型另算），慢的话十几分钟 |

安装脚本会自动准备 Git、Node.js、uv、Python 3.10.15 等工具，**不需要你提前装任何东西**。

---

## 1. 装

双击仓库里的 **`scripts\install.bat`**，等着它跑完。

成功时最后几行长这样：

```
================ 安装完成 ================
  Paddle 运行时：cpu

  下一步：
    1) 启动（二选一）
         浏览器版：双击 webui.bat   （会打印形如 http://127.0.0.1:5000 的地址）
         桌面窗口：双击 start.bat
    ...
```

### 如果没成功

脚本不会甩一堆英文报错给你，而是打成一段说明：

```
================ 安装没有完成 ================
  哪一步：安装 Python 依赖（第一次会比较慢，视网速可能十几分钟）
  为什么：Common Python dependency installation failed with exit code 1

  你可以这样做：
    1) 装不上通常是网络问题：换成手机热点或稍后重试
    2) 国内网络可以先执行：$env:UV_DEFAULT_INDEX = '...' 再重跑本脚本

  完整输出已保存在：D:\...\logs\install_20261001_120000.log
  照着上面做完，再运行一次 .\scripts\install.bat 即可。
=============================================
```

**照着「你可以这样做」做完，再双击一次 `install.bat` 就行**——它是可以反复跑的，已经装好的部分会自动跳过。

还想更细的排查，把那个 `logs\install_*.log` 发出来即可，里面有完整输出。

> 中途只重启电脑或关掉窗口也没关系，重新双击继续。

---

## 2. 启动

两个入口，选一个：

| | 怎么开 | 适合 |
|---|---|---|
| **浏览器版** | 双击 **`webui.bat`** | 最省事，自动帮你打开浏览器 |
| **桌面窗口** | 双击 **`start.bat`** | 想要独立窗口、托盘图标 |

启动后命令行会打印真实地址：

```
==> 启动 WebUI
    地址：http://127.0.0.1:5000
    停止：在这个窗口按 Ctrl+C
```

第一次启动要等 OCR 加载，**大约 10～60 秒**（日志里会出现 `PaddleOCR 引擎初始化完成`）。等不及可以先看下面的步骤，页面会自动刷新。

### 端口不是 5000 也没关系

上面的地址就是**你这次的地址**，照它打开即可。有冲突时：

- 5000 被别的软件占着 → AutoScriptor 自动换成 5001 并在窗口里说明，地址也会打印成新端口。
- 想固定一个端口：

  ```powershell
  .\webui.bat -Port 8080          # 临时指定一次
  $env:AUTOSCRIPTOR_PORT = '8080' # 或设成环境变量，长期有效
  ```

### 「双击了但没反应」

那多半是**上一次的实例还在后台跑**。此时会看到：

```
    AutoScriptor 已经在运行了。
    地址：http://127.0.0.1:5000
    已经在运行的实例只能有一个；要重启就先在它的窗口按 Ctrl+C 停掉。
```

浏览器会自动打开。要真的重启，就先回到原来那个命令行窗口按 `Ctrl+C`。

## 3. 认识界面

左边那一列就是全部功能，从上到下分三组：

```
CONTROL   资讯      游戏公告和礼包码
          总览      角色列表、调度状态、跨角色调度队列  ← 跑任务主要在这里
          调度      整个调度器的开关和日志
TASKS     任务列表  勾任务、调参数、排顺序              ← 配任务主要在这里
TOOLS     编辑器    写脚本 / 识别调试
          错误汇总  任务失败时的现场（截图 + 日志）
          QQ 通知   把结果发到 QQ
          检查更新  拉取源码更新
          设置      运行方式、模拟器路径、启动诊断      ← 出问题先来这里
          关于
```

右上角还可以切**账号**和**角色**——你的任务配置是跟角色走的。

## 4. 让它认识你的模拟器

> 模拟器装在哪个盘都行，这一步就是告诉 AutoScriptor 它在哪。

1. 打开侧栏 **设置**。
2. 往下来到 **启动诊断**，先点 **刷新**。
3. 看诊断结果：
   - Manager / ADB / App 都是**正常** → 跳过本节，直接用。
   - 出现「ADB path is missing」「未找到可用 MuMuManager」之类 → 继续第 4 步。
4. 回到上面的 **模拟器连接** 卡片，点 **自动定位 MuMu**。
   - 成功：三个路径（MuMu 安装目录 / MuMuManager 路径 / ADB 程序路径）会被自动填好，并提示已定位。
   - 失败：会告诉你「未找到完整 MuMu 路径，已扫描 N 个候选目录」。这时**手动填**：

     打开 MuMu 的安装目录（不知道在哪就在开始菜单里右键 MuMu 图标 → 打开文件位置），
     往里找 `nx_main` 文件夹，对照填写：

     | 字段 | 填什么 |
     |---|---|
     | MuMu 安装目录 | 例如 `C:\Program Files\Netease\MuMu` |
     | MuMuManager 路径 | 上面的目录 + `\nx_main\MuMuManager.exe` |
     | ADB 程序路径 | 上面的目录 + `\nx_main\adb.exe` |

     > 不同 MuMu 版本目录不一样：5.0 / 12 与 6.0 用 `nx_main`（就是上表）；
     > 更老的 12 用 `shell\MuMuManager.exe` 与 `shell\adb.exe`。拿不准就先点
     > **自动定位**，它会按版本自己找。

     填完再点一次 **刷新**。
5. 游戏服务器选你实际玩的那个（4399 官服 / 9游 / 当乐 / Vivo）。不是这些服就在下拉里选「其他」填包名。

### 顺便确认两件事

- **模拟器分辨率设成横屏 1280x720**。识别素材和点击坐标都按这个尺寸写；尺寸不对会有 warning，点击和识别可能偏。
- 诊断页的 **OCR** 显示「正常」即可。点 **截图探测** 可以额外验证截图链路（会连一下模拟器，不需要的时候不用点）。

## 5. 填账号

第一次启动时，右上角已经有一个占位账号 **`default`** 和占位角色 **`默认服务器/default`**——
它只是个空壳，还没有游戏账密。两种做法，任选一种：

### A. 最省事：给这个占位账号填上游戏账密

1. 点右上角账号下拉 → **修改账号密码**。
2. 填 **游戏账号**、**游戏密码**、**安全密码**：

   | 字段 | 说明 |
   |---|---|
   | 游戏账号 / 游戏密码 | 4399 或对应渠道的登录账密。**只加密保存在你本地** |
   | 安全密码 | 自定义的一串口令，用来加密上面那两项。**自己记住**，换电脑要用 |

3. 点 **确 定** → 提示「账号信息已更新」。
4. 再点账号下拉旁的**角色**下拉 → 选 **添加角色**，填你游戏里的 **服务器** 和 **角色名**。

### B. 想给账号起个名字：新建账号

1. 点右上角账号下拉 → **新建账号**。
2. 填写：

   | 字段 | 说明 |
   |---|---|
   | 账号名称 | 本地区分用，例如「大号」 |
   | 游戏账号 / 游戏密码 | 同上 |
   | 服务器 | 游戏里的服务器名，例如「水帘洞」 |
   | 角色名 | 你游戏里的角色名 |
   | 安全密码 | 同上 |

3. 点 **创 建**。右上角会变成新账号名，角色自动加进总览的调度队列。

> 一个账号下可以有多个角色（服务器 + 角色名）。每个角色有**自己的任务列表**，换角色就等于换一套配置。
> 游戏里改了密码，用 **修改账号密码** 更新即可，不用重建账号。

## 6. 配任务

1. 进 **任务列表**。
2. 左边是全部任务的顺序列表，右边是已启用的。顶部会显示 `启用数 / 总数`。
3. 点任务名打开编辑弹窗，里面四块：

   | 区块 | 作用 |
   |---|---|
   | 开关 | 这个任务要不要跑 |
   | 参数 | 该任务自己的设置（战斗配置、次数、难度…） |
   | 调度 | 下次什么时候跑：一次性 / 每天 05:00 / 每周一 05:00 / 每隔 N 小时 |
   | 调试直跑 | 跳过自动登录和失败恢复，用来现场试 |
4. 改完点保存。弹窗里的**调度**默认显示作者给的值，你改了就按你的来。
5. 想调顺序：直接拖动任务。拖到任务中部会创建分组。改完点 **保存任务配置**。

> **先只开一两个任务试水**，比如「登录」和一个简单的领取类任务。跑通了再多开。

---

## 7. 跑起来

### 先试单个任务

1. 确认模拟器开着、游戏能进去。
2. 任务列表里找到任务，点它右边的运行按钮。
3. 页面上能看到进度和日志。第一次它会自动登录游戏。

### 再试自动调度

1. 进 **总览**，确认 **队列** 里有你的角色（没有就点角色旁边的加入按钮）。
2. 点 **执行所有** 启动总调度。
3. 调度状态会变成「运行中」，并显示**下次执行**时间。

### 停下来

页面上任何地方（总览 / 调度 / 任务列表）的 **终止** / **终止执行** 按钮都是同一个入口，点一下即可。当前任务会在下一个可取消的点退出。

### 关掉程序

回到启动它的命令行窗口按 `Ctrl+C`（Electron 桌面版则关窗口 / 托盘退出）。

## 8. 出问题了怎么查

| 你看到的现象 | 先做什么 |
|---|---|
| 双击没反应 | 看第 2 节；多半是已经在运行 |
| 页面打不开 | 用命令行里打印的那个地址，别用固定的 5000 |
| 任务树是空的 | 等初始化完成（日志出现「后台初始化完成」），或点任务列表的 **刷新** |
| 点运行没反应 | 先在总览点 **重新验证** 解锁账号；确认没有别的任务在跑 |
| 提示找不到 MuMu / ADB | 第 4 节：设置 → 启动诊断 → 自动定位 MuMu，不行就手填 |
| 识别不准、点击偏 | 模拟器分辨率改成横屏 1280x720 |
| OCR 报错或一直没好 | 设置 → 启动诊断看 OCR 段；改了 GPU 开关要重启程序 |
| 任务失败 | 侧栏 **错误汇总**，里面是失败时的截图 + 日志 + 上下文 |
| 想改回去 | 删掉 `data\config.json` 会回到模板默认值（账号在 `data\accounts\`，不受影响） |

**报 bug 时请附上**：现象截图 + 错误汇总里那一条（尤其是 `error.log`）。日志在程序根目录的 `logs\` 下。

## 9. 数据放在哪

都在仓库根目录，备份就是整个拷走：

```text
data/config.json       全局配置（运行方式、模拟器路径…）
data/accounts/         账号、角色、每个角色的任务配置（含加密凭据）
data/custom_task/      你自己在编辑器里存的任务
data/character/        你自己的职业脚本
logs/                  日志、截图、错误归档、安装日志
```

`data/accounts/` 里的凭据用你的**安全密码**加密。换电脑时把整个 `data\` 拷过去，在新机器上验证账号时输入同一个安全密码即可。

## 10. 更新

```powershell
.\scripts\update.bat
```

拉取源码更新；如果依赖有变化，再跑一次 `.\scripts\install.bat`。也可以在 WebUI 的 **检查更新** 页点检查。
