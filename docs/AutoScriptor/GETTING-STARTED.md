# 从零开始

1. MuMu/游戏横屏1280x720。
2. ZIP 解压到可写目录，运行 `scripts\install.bat`。
3. `webui.bat`/`start.bat` 启动，认打印地址。
4. 设置定位 MuMu、查看诊断。
5. 填账密，以安全密码加密/解锁，添加服务器/角色。
6. 任务列表配置保存，直跑保留现场；总览加队列再执行所有。
7. 终止协作取消，Ctrl+C/托盘退出。

排错看错误汇总；备份 data/，换机须原安全密码。

编辑器「新手教程」演练流程；「API 文档」查版本/参数/示例。两者不操作真机、不改草稿。

参见 [安装](INSTALL.md)、[验收](webui/user-trajectories.md)。
