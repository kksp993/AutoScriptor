MuMu 安装目录
MuMu 模拟器的安装根目录（包含 shell 或 nx_main 子文件夹）
如何找到 MuMu 安装目录？
  1. 右键桌面上的「MuMu模拟器」快捷方式 → 选择「打开文件所在位置」
  2. 在弹出的文件夹中向上一级，该目录通常就是安装目录（包含 nx_main 或 shell 子文件夹）
  3. 常见安装路径：C:\Program Files\Netease\MuMu 或 D:\MuMu Player 12
  4. 如果未安装 MuMu，请先下载安装：MuMu 模拟器官网 ↗
?
模拟器可执行文件
MuMuPlayer.exe 或 MuMuManager.exe 的完整路径
找不到模拟器可执行文件？
  1. 在 MuMu 安装目录下查找以下文件（二选一）：
    nx_main\MuMuManager.exe（旧版 MuMu）
    shell\MuMuPlayer.exe（MuMu Player 12）
  2. 选中安装目录后，程序会尝试自动推导此路径。如果推导失败，请用「浏览…」手动选择 exe 文件
  3. 如果这些文件都不存在，可能 MuMu 安装不完整，建议重新安装：MuMu 官网下载 ↗
?
ADB 可执行文件
adb.exe 的完整路径（通常在模拟器安装目录的 shell 子文件夹中）
ADB 是什么？怎么找？
  1. ADB（Android 调试桥）是连接模拟器的工具，MuMu 自带了一份，无需单独安装
  2. 在 MuMu 安装目录下查找：
    nx_main\adb.exe（旧版 MuMu）
    shell\adb.exe（MuMu Player 12）
  3. 如果文件不存在，可能安装不完整。也可使用 Android SDK 中的 adb：Android Platform Tools ↗
?
模拟器设备连接
通过 ADB 检测模拟器实例是否在线（需要模拟器已启动）
设备未连接怎么办？
  1. 这不影响安装，只是说明模拟器当前未运行。安装完成后启动模拟器即可
  2. 如果模拟器已启动但仍显示未连接：
    • 打开 MuMu 多开器，确认实例正在运行
    • MuMu 12 默认 ADB 端口为 16384（第 1 个实例），每增加一个实例端口 +32
    • 确认防火墙或安全软件未拦截 ADB 通信
  3. 端口对照：实例 0 → 16384，实例 1 → 16416，实例 2 → 16448…
